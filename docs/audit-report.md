## 3. Important Source Folders and Files

- `gpclean/main.py`
  - Launches the PySide login UI.
  - Imports login view/controller and main submission model/view.
  - Contains mojibake/encoding-corrupted comments and log strings.

- `gpclean/ui/login/`
  - Login UI and controller layer.
  - `login_controller.py` checks MongoDB auth data and opens the file-drop workflow.

- `gpclean/ui/main/`
  - Main submitter UI model/view/controller.
  - `model.py` detects Maya, Blender, or Nuke, resolves current scene paths, and reads reservation data.
  - `controller.py` is currently a placeholder.
  - `view.py` populates UI fields and wires the send-to-Deadline button.

- `gpclean/ui/file_drop/`
  - File-drop UI flow used after login.
  - Currently displays current/upload paths and accepts dropped file URLs, but drop handling appears minimal.

- `gpclean/backend/authDB/`
  - MongoDB connection, Google Sheets import script, auth seeding script, Excel auth workbook generation.
  - Contains public-doc/security cleanup risks listed below.

- `gpclean/gpclean_submit/`
  - More structured Deadline submission package.
  - `cli.py` is the DCC dispatch entry point.
  - `core/deadline.py` writes Deadline job/plugin info temp files and invokes `deadlinecommand SubmitJob`.
  - `core/job_builder.py` builds Deadline job/plugin info for MayaBatch and Blender.
  - `core/types.py` defines `SceneInfo`, `RenderSettings`, and `JobSpec`.
  - `dcc/maya_adapter.py` gathers scene/render settings from Maya and validates Arnold/mtoa.
  - `dcc/blender_adapter.py` gathers scene/render settings from Blender.

- `blender/gpclean/`
  - Appears to be a copied package tree rather than a clean plugin-only package.
  - It duplicates many `gpclean/` files and generated bytecode.

- `ShaderMain.py` and `ShaderSetup.py`
  - Maya shader automation scripts for Substance Painter texture maps to V-Ray-style shader wiring.
  - These appear related to DCC tooling but not central to the Deadline render farm portfolio story unless intentionally included as supporting pipeline tools.

## 5. Key Modules and Their Purposes

- PySide UI layer:
  - Login, file drop, and submitter windows are implemented with PySide6 fallback to PySide2.
  - UI definitions are stored as `.ui` files.

- MongoDB auth/reservation layer:
  - `db.py` connects to MongoDB and exposes `reservation_collection` and `auth_collection`.
  - `login_controller.py` authenticates users by `student_id` and SHA-256 password hash.
  - `main/model.py` reads reservation slots for the logged-in student.

- Google Sheets reservation import:
  - `sheetToMongo.py` reads reservation data from Google Sheets and upserts reservation slots into MongoDB.
  - The paper claims Google Sheets / Apps Script reservation workflow. The code shows a Python `gspread` import path, not a GAS implementation in-repo.

- Deadline submission builder:
  - `gpclean_submit/core/job_builder.py` creates Deadline job info and plugin info strings.
  - Supports MayaBatch for Maya and Blender plugin submission for Blender.

- DCC adapters:
  - `maya_adapter.py` queries Maya scene path, project path, render globals, renderable camera, render layers, frame range, renderer, and version.
  - `blender_adapter.py` queries Blender file path, frame range, renderer, output path, and version.

- Path/preflight utilities:
  - `paths.py` normalizes backslashes to forward slashes and builds output paths.
  - `preflight.py` currently checks only scene path presence and frame range validity.

- Shader helper scripts:
  - Top-level shader scripts automate texture node creation and material connections in Maya.

## 7. Sensitive Data Risks

The public repository should not expose operational identifiers or credentials. Existing risks found during inspection:

- `gpclean/ui/login/login_controller.py`
  - Contains commented Deadline MEL source lines using an internal server IP and internal repository path.
  - Public docs should replace these with `<internal-server-name>` or `<nas-server-ip>` and `<internal-path>`.

- `gpclean/backend/authDB/db.py`
  - Contains a MongoDB URI in source code.
  - For public docs, use `<mongodb-uri>`.
  - For code hardening later, this should be environment-configured.

- `gpclean/backend/authDB/sheetToMongo.py`
  - Contains a local Google credential JSON path.
  - Contains a real/private Google Sheet title and worksheet naming convention.
  - Public docs should use `<google-sheet-url>` and avoid local credential paths.

- `gpclean/backend/authDB/auth_hashed_pw.py`
  - Contains sample student IDs and plaintext sample passwords.
  - Also includes example MongoDB output with hashes.
  - Public docs should use `<student-id>` and avoid passwords/hashes.

- `gpclean/backend/authDB/exel_creator.py`
  - Contains sample student IDs and plaintext sample passwords.

- `gpclean/backend/authDB/auth.xlsx` and `blender/gpclean/backend/authDB/auth.xlsx`
  - Committed workbooks are a high-risk artifact until verified as dummy-only.
  - Do not document workbook contents publicly.
  - Recommended later action: replace with a sanitized fixture or remove from tracked files, but this audit task did not delete files.

- Private technical paper:
  - Contains real institutional/personally identifying metadata and an Arnold license server example.
  - Public README/docs should not reproduce those raw values.
  - Use `<license-server-ip>`, `<student-id>`, `<internal-server-name>`, and other approved placeholders.
