# Screenshots

This directory is for public-safe screenshots only.

Before committing any image, remove or blur:

- IP addresses
- NAS/UNC paths
- Deadline Repository paths
- usernames, student IDs, account names
- license server values
- Google Sheet URLs
- database URIs
- logs containing machine names or internal paths

## Folders

- `renderfarm-usage-guide/`: redacted screenshots for the render farm usage guide.
